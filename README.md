<summary>What was my professional experience at <a href="https://github.com/Resound-fm">Resound</a> (startup) 🎵 like?</summary>
<br>
I had 1.1 years of experience at Resound, and it was pretty intensive. My time there is so valuable to me because I learned a lot and challenged myself with almost every task. For some context...  

1. **My first weeks** I was extremely passionate about my first task—setting up user registration! I ramped up and got up to speed immediately, especially after knowing the beta launch would be in a few weeks. I knew database design would be essential and took responsibility for making sure our user schema was scalable even if development was rapid. The task I was given was much larger than expected because, in addition to creating users in the database, I also had to create Django forms and templates for email, name, and password validation. And password validation was complex, with specific requirements for special characters, numbers, and upper/lower case letters defined by our UI/UX designer. And unit tests for all registration combinations! I also had to connect all of this with the frontend. I consistently corresponded with the designer to ensure frontend accuracy so the beta launch went smoothly. And I delivered on time with good coding standards and best practices, even though the task was much larger than expected! 🚀  

2. **I thought audio processing was so cool.** That's why I joined the startup. So I took on the challenging umbrella of tasks—exports! That included exporting audio in various formats, generating AAF files so creators could load their edits with audio into mainstream editors, post-production audio editing like removing silences, processing multiple tracks within each project, and combining multiple segment clips within each track. It was a lot, but I really wanted to work on this. I felt like an audio engineer making audio edits, but with code! 🎧 Each of the subtasks often required deep research, especially the ones involving AAF format and FFmpeg silence detection.
